# NOOPI Mafia Game Specification

> Version: V1
> Service: NOOPI
> Game: Mafia

---

## 1. 개요

NOOPI 마피아는 같은 공간에 모인 플레이어들이 각자의 스마트폰을 사용하여 진행하는 실시간 오프라인 파티 게임이다.

별도의 사회자 없이 NOOPI가 다음 게임 진행을 담당한다.

```text
역할 배정
→ 첫 번째 밤
→ 낮
→ 토론
→ 처형 투표
→ 처형
→ 밤
→ 낮
→ 반복
→ 게임 종료
```

플레이어 간 토론과 추리는 실제 자리에서 자유롭게 진행한다.

NOOPI는 다음 요소를 관리한다.

* 역할 배정
* 밤 행동
* 시민 의심
* 경찰 조사
* 마피아 공격
* 의사 치료
* 처형 투표
* 사망 처리
* 승리 조건 판정
* 게임 상태 동기화

NOOPI는 토론 순서, 발언 순서, 발언 시간 등 오프라인 대화에는 관여하지 않는다.

---

# 2. 게임 인원

지원 인원:

```text
최소 4명
최대 12명
```

인원별 역할 구성은 다음과 같다.

| 인원 | 마피아 | 경찰 | 의사 | 시민 |
| -: | --: | -: | -: | -: |
|  4 |   1 |  1 |  0 |  2 |
|  5 |   1 |  1 |  1 |  2 |
|  6 |   1 |  1 |  1 |  3 |
|  7 |   2 |  1 |  1 |  3 |
|  8 |   2 |  1 |  1 |  4 |
|  9 |   2 |  1 |  1 |  5 |
| 10 |   2 |  1 |  1 |  6 |
| 11 |   2 |  1 |  1 |  7 |
| 12 |   3 |  1 |  1 |  7 |

V1에서는 플레이어 수를 기준으로 역할 구성을 서버가 자동 결정한다.

방장이 다음 항목을 임의로 변경할 수 없다.

* 마피아 수
* 경찰 수
* 의사 수
* 시민 수

---

# 3. 팀

게임에는 두 팀이 존재한다.

## 3.1 마피아팀

```text
MAFIA
```

마피아만 포함된다.

## 3.2 시민팀

```text
POLICE
DOCTOR
CITIZEN
```

경찰, 의사, 시민이 시민팀에 포함된다.

---

# 4. 역할

## 4.1 마피아 (MAFIA)

마피아팀 소속이다.

목표는 시민팀을 제거하여 마피아팀의 승리 조건을 만족시키는 것이다.

### 기본 규칙

* 마피아가 여러 명이면 서로의 정체를 알고 시작한다.
* 첫 번째 밤에는 공격할 수 없다.
* 두 번째 밤부터 공격할 수 있다.
* 다른 마피아는 공격 대상으로 선택할 수 없다.
* 사망한 플레이어는 선택할 수 없다.
* 시민 의심 기능을 사용할 수 없다.

---

## 4.2 경찰 (POLICE)

시민팀 소속이다.

매일 밤 생존자 한 명을 조사할 수 있다.

### 조사 결과

정확한 역할은 알려주지 않는다.

다음 두 결과 중 하나만 제공한다.

```text
마피아입니다.
```

또는

```text
마피아가 아닙니다.
```

예:

```text
철수 = MAFIA

→ 철수님은 마피아입니다.
```

```text
철수 = DOCTOR

→ 철수님은 마피아가 아닙니다.
```

### 기본 규칙

* 첫 번째 밤부터 조사할 수 있다.
* 자신을 조사할 수 없다.
* 사망한 플레이어를 조사할 수 없다.
* 조사 결과는 경찰 본인에게만 공개한다.
* 시민 의심 기능을 사용할 수 없다.

---

## 4.3 의사 (DOCTOR)

시민팀 소속이다.

마피아에게 공격받은 플레이어를 치료하여 사망을 막을 수 있다.

### 기본 규칙

* 첫 번째 밤에는 치료하지 않는다.
* 두 번째 밤부터 치료할 수 있다.
* 자신을 치료할 수 있다.
* 사망한 플레이어를 치료할 수 없다.
* 직전 밤에 치료한 플레이어를 연속으로 치료할 수 없다.
* 시민 의심 기능을 사용할 수 없다.

예:

```text
마피아 공격 → 철수
의사 치료   → 철수

결과 → 철수 생존
```

치료 성공 여부는 의사에게 별도로 알려주지 않는다.

---

## 4.4 시민 (CITIZEN)

시민팀 소속이다.

공격, 조사, 치료 능력은 없다.

대신 NOOPI 마피아의 고유 기능인 `의심(Suspicion)`을 사용할 수 있다.

### 기본 규칙

* 매일 밤 생존자 한 명을 의심할 수 있다.
* 자신은 선택할 수 없다.
* 사망한 플레이어는 선택할 수 없다.
* 한 밤에 한 번만 제출할 수 있다.
* 제출 후 변경할 수 없다.
* 낮에는 의심을 제출하거나 변경할 수 없다.

---

# 5. 게임 시작

방장이 게임 시작을 요청하면 서버는 현재 참가 인원을 검증한다.

유효한 경우 역할을 무작위로 배정한다.

각 플레이어에게 자신의 역할만 공개한다.

예:

```text
당신은 경찰입니다.

매일 밤 한 명을 조사하여
마피아인지 확인할 수 있습니다.

[확인 완료]
```

다른 플레이어의 역할은 확인할 수 없다.

모든 플레이어가 역할 확인을 완료하면 첫 번째 밤으로 이동한다.

```text
ROLE_REVEAL
    ↓
FIRST_NIGHT
```

역할 확인은 각 플레이어가 `[확인 완료]`를 눌러 서버에 제출해야 완료된다.
마피아 역시 자신의 역할과 동료 마피아를 확인한 뒤 같은 확인 행동을
제출한다. 제출 후에는 역할 확인을 다시 제출할 수 없다.

---

# 6. 첫 번째 밤

게임은 역할 확인 직후 바로 첫 번째 밤으로 시작한다.

첫 번째 밤에는 아무도 사망하지 않는다.

역할별 행동은 다음과 같다.

| 역할      | 행동            |
| ------- | ------------- |
| MAFIA   | 동료 마피아 확인     |
| POLICE  | 플레이어 1명 조사    |
| DOCTOR  | 행동 없음 / 확인 완료 |
| CITIZEN | 플레이어 1명 의심    |

---

## 6.1 첫날 마피아

마피아가 여러 명이면 동료 마피아를 확인한다.

예:

```text
당신은 마피아입니다.

함께하는 마피아
- 철수
```

마피아가 한 명이라면:

```text
당신은 유일한 마피아입니다.
```

첫 번째 밤에는 공격할 수 없다.

마피아 동료 목록은 `ROLE_REVEAL` 이후에도 본인 화면에서 다시 확인할 수
있으며 재접속 후에도 복구한다.

---

## 6.2 첫날 경찰

경찰은 첫 번째 밤부터 한 명을 조사한다.

```text
조사할 플레이어를 선택하세요.
```

선택 후 경찰에게만 조사 결과를 보여준다.

조사 결과는 제출 응답에서 즉시 보여주고 밤별 개인 조사 기록으로 저장한다.
경찰은 이후에도 본인의 과거 조사 대상과 `마피아 여부` 결과를 다시 확인할
수 있으며, 다른 플레이어에게는 공개하지 않는다.

---

## 6.3 첫날 의사

의사는 첫 번째 밤에는 행동하지 않는다.

```text
첫 번째 밤입니다.

오늘 밤에는 치료할 수 없습니다.

[확인 완료]
```

---

## 6.4 첫날 시민

시민은 첫 번째 밤부터 의심할 플레이어 한 명을 선택한다.

```text
누가 마피아일 것 같나요?

가장 의심되는 사람 한 명을 선택해주세요.
```

해당 선택은 첫 번째 밤의 의심 기록으로 저장한다.

---

# 7. 일반 밤

두 번째 밤부터 모든 역할의 밤 능력이 활성화된다.

모든 생존 플레이어는 동시에 행동한다.

| 역할      | 밤 행동     |
| ------- | -------- |
| MAFIA   | 공격 대상 선택 |
| POLICE  | 조사 대상 선택 |
| DOCTOR  | 치료 대상 선택 |
| CITIZEN | 의심 대상 선택 |

역할별로 순차 진행하지 않는다.

```text
마피아
경찰
의사
시민

→ 동시에 행동
```

모든 생존자의 필수 행동이 완료되면 밤을 종료한다.

---

# 8. 마피아 공격

마피아는 자신과 다른 마피아를 제외한 생존자 한 명을 선택한다.

## 8.1 마피아 1명

선택한 플레이어가 공격 대상이 된다.

```text
MAFIA → 철수

공격 대상 = 철수
```

## 8.2 마피아 여러 명

각 마피아가 독립적으로 공격 대상을 선택한다.

가장 많은 선택을 받은 플레이어를 공격한다.

예:

```text
마피아 A → 철수
마피아 B → 철수
마피아 C → 영희

공격 대상 = 철수
```

## 8.3 공격 동률

최다 선택이 동률이면 공격에 실패한다.

예:

```text
마피아 A → 철수
마피아 B → 영희

결과 = 공격 실패
```

이 경우 해당 밤에는 마피아 공격으로 인한 사망자가 발생하지 않는다.

---

# 9. 경찰 조사

경찰은 자신을 제외한 생존자 한 명을 선택한다.

선택 후 조사 결과를 경찰에게만 제공한다.

```text
조사 대상 = 철수
역할 = MAFIA

→ 철수님은 마피아입니다.
```

또는:

```text
조사 대상 = 철수
역할 = CITIZEN

→ 철수님은 마피아가 아닙니다.
```

경찰의 조사 결과는 시스템을 통해 다른 플레이어에게 공유하지 않는다.

---

# 10. 의사 치료

의사는 자신을 포함한 생존자 한 명을 선택한다.

단, 직전 밤에 치료했던 플레이어는 선택할 수 없다.

```text
Night 2
의사 → 철수

Night 3
철수 선택 불가
```

마피아 공격 대상과 치료 대상이 동일하면 사망을 막는다.

```text
공격 대상 = 철수
치료 대상 = 철수

→ 사망자 없음
```

치료 성공 여부는 별도로 공개하지 않는다.

---

# 11. 시민 의심

의심은 `CITIZEN` 역할만 사용할 수 있다.

경찰, 의사, 마피아는 참여하지 않는다.

시민은 매일 밤 자신을 제외한 생존자 한 명을 선택한다.

```text
누가 마피아일 것 같나요?

○ 철수
○ 영희
○ 민수
```

선택 완료 후 해당 밤에는 변경할 수 없다.

낮에도 변경할 수 없다.

---

# 12. 의심 기록

시민의 의심은 밤별 기록으로 관리한다.

개념적인 데이터:

```text
nightNo
citizenPlayerId
targetPlayerId
createdAt
```

예:

```text
Night 1
민수 → 철수

Night 2
민수 → 철수

Night 3
민수 → 영희
```

동일한 시민은 하나의 밤에 하나의 의심 기록만 생성할 수 있다.

---

# 13. 의심 집계

밤 종료 시 해당 밤의 시민 의심을 집계한다.

예:

```text
시민 A → 철수
시민 B → 철수
시민 C → 영희
```

집계:

```text
철수 = 2
영희 = 1
민수 = 0
```

전체 결과는 공개하지 않는다.

---

# 14. 개인 의심 결과

모든 플레이어는 자신이 받은 의심 수만 확인할 수 있다.

예:

```text
지난밤 시민 2명이
당신을 의심했습니다.
```

0명이라면:

```text
지난밤 당신을 의심한
시민은 없습니다.
```

다음 정보는 공개하지 않는다.

```text
X 누가 나를 의심했는지
X 다른 플레이어가 받은 의심 수
X 시민별 의심 대상
X 전체 의심 순위
```

따라서 플레이어가 낮에 자신의 의심 수를 말하더라도 다른 플레이어는 해당 발언이 사실인지 확인할 수 없다.

---

# 15. 밤 결과 처리

모든 필수 밤 행동이 완료되면 서버가 밤 결과를 계산한다.

기본 처리 흐름:

```text
모든 밤 행동 완료
        ↓
마피아 공격 대상 결정
        ↓
의사 치료 여부 확인
        ↓
사망 여부 결정
        ↓
시민 의심 집계
        ↓
승리 조건 검사
        ↓
낮 시작
```

경찰 조사 결과는 경찰 개인에게만 제공한다.

---

# 16. 낮 시작

사망자가 존재하면 모든 플레이어에게 공개한다.

예:

```text
아침이 되었습니다.

철수님이 지난밤 사망했습니다.

철수님의 역할은
경찰이었습니다.
```

사망자가 없다면:

```text
아침이 되었습니다.

지난밤 아무도 죽지 않았습니다.
```

각 생존 플레이어에게는 자신의 의심 수도 함께 제공한다.

```text
지난밤 시민 2명이
당신을 의심했습니다.
```

---

# 17. 첫 번째 낮

첫 번째 밤에는 공격이 없으므로 사망 결과를 표시하지 않는다.

```text
첫 번째 낮이 시작되었습니다.

대화를 통해
마피아를 찾아보세요.

지난밤 시민 1명이
당신을 의심했습니다.
```

---

# 18. 낮 토론

낮에는 플레이어들이 실제 자리에서 자유롭게 토론한다.

NOOPI는 다음 항목에 관여하지 않는다.

```text
발언 순서
발언 횟수
발언 시간
토론 시간
```

낮에는 역할별 능력을 사용할 수 없다.

시민 역시 의심 대상을 변경할 수 없다.

방장이 충분히 토론했다고 판단하면 `투표 시작`을 요청한다.

## 18.1 결과 단계 진행

결과 화면을 모든 참가자가 확인할 수 있도록 다음 전환은 방장이 명시적으로
진행한다.

```text
VOTE_RESULT → EXECUTION
EXECUTION → NIGHT
NIGHT_RESULT → DAY
```

방장이 아닌 플레이어에게는 다음 단계 행동을 제공하지 않고 대기 상태를
표시한다. 첫 번째 밤은 공격과 사망 결과가 없으므로 모든 필수 행동이
완료되면 별도 `NIGHT_RESULT` 없이 첫 번째 `DAY`로 자동 전환한다.

장기 미접속 플레이어 제외 정책은 V1 마피아 게임 범위에서 정의하지 않는다.

---

# 19. 처형 투표

처형 투표는 시민의 `의심`과 별개의 시스템이다.

## 의심

```text
참여자: CITIZEN만
시점: 밤
목적: 추리/심리 정보
처형 영향: 없음
```

## 처형 투표

```text
참여자: 모든 생존자
시점: 낮 토론 이후
목적: 처형자 결정
```

모든 생존자는 자신을 제외한 생존자 한 명에게 투표한다.

```text
마피아라고 생각하는 사람에게 투표하세요.

○ 철수
○ 영희
○ 민수
```

---

# 20. 투표 진행

모든 생존자의 투표가 완료될 때까지 기다린다.

진행 상황은 다음 수준으로만 공개한다.

```text
5 / 7명 투표 완료
```

투표 진행 중에는 다음 정보를 공개하지 않는다.

```text
X 현재 득표 수
X 누가 투표했는지
X 누가 누구에게 투표했는지
```

---

# 21. 투표 결과

모든 투표가 완료되면 최종 득표 수를 공개한다.

예:

```text
투표 결과

철수 4표
영희 2표
민수 1표
```

개인별 투표 내역은 공개하지 않는다.

즉:

```text
민수 → 철수
영희 → 철수
```

같은 정보는 게임 종료 후에도 기본적으로 공개하지 않는다.

---

# 22. 동률 및 재투표

최다 득표자가 여러 명이면 해당 후보들만 대상으로 재투표한다.

예:

```text
철수 3표
영희 3표
민수 1표
```

재투표 대상:

```text
철수
영희
```

재투표에서도 동률이면 다시 재투표한다.

### 규칙

```text
재투표 횟수 제한 없음
랜덤 처형 없음
```

최종적으로 한 명의 최다 득표자가 결정될 때까지 반복한다.

---

# 23. 처형

최종 최다 득표자 한 명을 사망 처리한다.

사망자의 역할을 모든 플레이어에게 공개한다.

예:

```text
철수님이 처형되었습니다.

철수님의 역할은
시민이었습니다.
```

처형 직후 승리 조건을 검사한다.

승리 조건이 충족되지 않으면 다음 밤으로 이동한다.

---

# 24. 사망자

사망한 플레이어는 이후 게임 행동에서 제외된다.

사망자는 다음 행동을 할 수 없다.

```text
X 마피아 공격
X 경찰 조사
X 의사 치료
X 시민 의심
X 처형 투표
```

사망자 화면:

```text
당신은 사망했습니다.

게임이 끝날 때까지
생존자들의 게임을 지켜봐 주세요.
```

사망자에게 다른 생존자의 역할을 공개하지 않는다.

---

# 25. 시민팀 승리

생존한 마피아가 0명이 되면 시민팀이 즉시 승리한다.

```text
aliveMafia == 0
```

결과:

```text
시민팀 승리
```

---

# 26. 마피아팀 승리

생존한 마피아 수가 생존한 시민팀 수 이상이 되면 마피아팀이 즉시 승리한다.

```text
aliveMafia >= aliveCitizenTeam
```

예:

```text
생존 마피아 = 2
생존 시민팀 = 2

→ 마피아팀 승리
```

---

# 27. 승리 조건 검사 시점

승리 조건은 플레이어 사망이 확정되는 시점마다 검사한다.

```text
밤 사망 처리
→ WIN_CHECK

처형 처리
→ WIN_CHECK
```

승리 조건이 충족되면 다음 페이즈로 이동하지 않고 즉시 게임을 종료한다.

---

# 28. 게임 종료

게임 종료 시 승리 팀을 공개한다.

예:

```text
시민팀 승리!

모든 마피아를 찾아냈습니다.
```

또는:

```text
마피아팀 승리!

마피아가 마을을 장악했습니다.
```

게임 종료 후 모든 플레이어의 역할을 공개한다.

예:

```text
마피아
- 철수
- 영희

경찰
- 민수

의사
- 지수

시민
- 현우
- 수진
- 준호
```

---

# 29. 게임 종료 후 확장 기능

시민의 밤별 의심 기록을 이용하여 추후 게임 결과 콘텐츠를 제공할 수 있다.

V1 필수 기능은 아니다.

예:

### 날카로운 시민

실제 마피아를 가장 먼저 의심한 시민.

### 의심의 중심

게임 전체에서 가장 많은 시민 의심을 받은 플레이어.

### 억울한 시민

시민팀이면서 누적 의심을 가장 많이 받은 플레이어.

### 끝까지 의심

실제 마피아를 여러 밤 연속으로 의심한 시민.

# 30. 게임 상태

개념적인 게임 상태는 다음과 같이 구성한다.

```text
WAITING
ROLE_REVEAL
FIRST_NIGHT
DAY
VOTING
REVOTING
VOTE_RESULT
EXECUTION
NIGHT
NIGHT_RESULT
GAME_OVER
```

세부 구현 시 `WIN_CHECK`는 독립 상태가 아니라 서버 내부 판정 로직으로 처리할 수 있다.

   │

   │    │

# 33. 구현 시 중요 원칙

### 서버 권한

다음 판정은 반드시 서버에서 수행한다.

* 역할 배정
* 현재 페이즈 검증
* 플레이어 생존 여부 검증
* 역할별 행동 가능 여부 검증
* 행동 대상 검증
* 시민 의심 제출 검증
* 마피아 공격 대상 결정
* 의사 치료 판정
* 경찰 조사 결과 판정
* 투표 집계
* 재투표 대상 결정
* 사망 처리
* 승리 조건 판정

클라이언트의 요청 값을 신뢰하여 게임 결과를 결정하지 않는다.

### 정보 노출

플레이어별 비공개 정보가 다른 플레이어에게 전달되지 않도록 한다.

특히 다음 정보는 권한에 따라 필터링해야 한다.

```text
플레이어 역할
경찰 조사 결과
마피아 동료 정보
시민별 의심 대상
개인별 처형 투표 대상
```

### 실시간 동기화

다음 상태 변화는 참가자들에게 실시간으로 동기화한다.

```text
게임 시작
역할 확인 진행 상태
밤 행동 완료 인원
밤 종료
낮 시작
개인 의심 수
투표 시작
투표 완료 인원
투표 결과
재투표 시작
사망
게임 종료
```

개인 정보가 포함된 이벤트는 해당 플레이어에게만 전달해야 한다.

### 행동 API 형태

밤 행동은 역할별 Endpoint를 여러 개 두지 않고 하나의 Endpoint에서 다음
행동 타입을 구분한다.

```text
ATTACK
INVESTIGATE
HEAL
SUSPECT
CONFIRM
```

서버는 요청 플레이어의 역할, 현재 밤, 허용 행동 타입과 대상 후보를 모두
검증한다.
